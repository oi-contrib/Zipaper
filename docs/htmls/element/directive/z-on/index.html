z-on

使用

绑定事件，例如： 

<button z-on:click="doit">按钮</button>

其中doit定义如下： 

methods: {
    doit(event, target){
        // event是事件，target在这里就是按钮元素
    }
}

此外，还可以添加修饰符，比如： 

<button z-on:click.stop.once="doit">按钮</button>

修饰符可以使用任意多个，可选的如下：

  • prevent：阻止默认事件
  • stop：阻止冒泡
  • once：只执行一次
  • enter：回车

传递参数

始于 v0.3.0

绑定的事件，也支持传递参数，比如： 

<button z-on:click="doit('我是一个参数')">按钮</button>

那么doit定义就如下： 

methods: {
    doit(info){
        // info的值就是'我是一个参数'
    }
}

当然，也可以是类似z-bind的拼接值，比如： 

<button z-on:click="doit("水果："+fruit)">按钮</button>

此时doit定义就如下： 

data(){
    return {
        fruit:"苹果"
    }
},
methods: {
    doit(info){
        // info的值就是'水果：苹果'
    }
}

当然，原来的 event 和 target 作为当前指令的局部值，依旧可以用，比如： 

<button z-on:click="doit($event, $target)">按钮</button>
